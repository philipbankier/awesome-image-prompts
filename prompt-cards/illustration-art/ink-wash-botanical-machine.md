# Ink-Wash Botanical Machine

## Use this when

Use this card for an invented botanical-mechanical object study with a declared functional idea. It is not for copying an existing botanical plate, patent figure, or artist. Use a Recipe when component preservation or repair needs run evidence.

## Required inputs

Provide the invented machine purpose, plant structures, mechanical parts, connection logic, silhouette, wash colors, paper field, camera view, aspect ratio, and exclusions.

## Prompt

```text
SCENE: Place one invented botanical machine on {PAPER_FIELD}, isolated with generous negative space and viewed from {CAMERA_VIEW}.
SUBJECT: Depict {MACHINE_PURPOSE} as a coherent hybrid of {PLANT_STRUCTURES} and {MECHANICAL_PARTS} following {CONNECTION_LOGIC}.
DETAILS: Preserve {SILHOUETTE}, use {WASH_COLORS}, controlled ink contours, translucent pooling, dry-brush accents, and visible attachment points that make the fictional mechanism understandable.
CONSTRAINTS: Do not add labels, real patents, logos, signatures, watermarks, impossible free-floating parts, copied botanical specimens, or any named artist's manner. Also avoid {MUST_AVOID}.
OUTPUT INTENT: Return one original {ASPECT_RATIO} ink-wash object study with readable anatomy and mechanics.
```

## Variables

- `{PAPER_FIELD}` and `{CAMERA_VIEW}`: backing and viewpoint.
- `{MACHINE_PURPOSE}`: fictional function stated in one sentence.
- `{PLANT_STRUCTURES}` and `{MECHANICAL_PARTS}`: exact component lists.
- `{CONNECTION_LOGIC}` and `{SILHOUETTE}`: assembly and overall form.
- `{WASH_COLORS}`: restrained approved palette.
- `{MUST_AVOID}`: additional project-specific exclusions.
- `{ASPECT_RATIO}`: delivery crop.

## Negative constraints

No real patent imagery, botanical plate copying, detached components, text, brands, signatures, watermarks, photorealism, or living-artist imitation.

## Quick check

Trace every plant-to-machine connection, verify the declared silhouette and components, and reject unexplained floating parts or derivative imagery.
