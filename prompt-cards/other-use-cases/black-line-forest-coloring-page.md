# Black-Line Forest Coloring Page

## Use this when

Use this card for a printable black-line coloring page built from a fictional forest scene. Use a Recipe when exact educational content, print production, or accessibility review matters.

## Required inputs

- Intended age range and line-complexity level.
- Exact animal, plant, terrain, and object manifest.
- Page size, border allowance, composition, and exclusions.

## Prompt

```text
SCENE
Create a flat black-line coloring page showing {FOREST_SETTING}, composed for {PAGE_SIZE}.

SUBJECT
Center the scene on exactly {SUBJECT_MANIFEST}, arranged according to {COMPOSITION}.

DETAILS
Use {LINE_STYLE}, {DETAIL_LEVEL}, and {FOREGROUND_BACKGROUND_PLAN}. Respect {BORDER_ALLOWANCE}, and keep every enclosed region large enough for the {AGE_RANGE} audience to color comfortably.

CONSTRAINTS
Pure black lines on a clean white field only. No gray, shading, color, hatching that closes tiny spaces, clipped subject, hidden limbs, duplicate animals, frightening imagery, border unless requested, letters, numbers, caption, signature, logo, or watermark. Also avoid {MUST_AVOID}.

OUTPUT INTENT
Return one complete portrait coloring page with consistent line weight, clear closed shapes, generous margins, and no print-readiness claim.
```

## Variables

- `{FOREST_SETTING}`: woodland type, season, and terrain.
- `{PAGE_SIZE}`: target paper orientation and ratio.
- `{SUBJECT_MANIFEST}`: exact animals, plants, and objects with counts.
- `{COMPOSITION}`: placement, focal subject, and open areas.
- `{LINE_STYLE}`: contour weight, roundness, and visual character.
- `{DETAIL_LEVEL}`: simple, moderate, or intricate detail target.
- `{FOREGROUND_BACKGROUND_PLAN}`: layer order and depth cues.
- `{AGE_RANGE}`: intended audience range used only to set complexity.
- `{BORDER_ALLOWANCE}`: required clear margin or approved border treatment.
- `{MUST_AVOID}`: additional project-specific exclusions.

## Negative constraints

- No copyrighted characters, recognizable illustration franchise, or named artist imitation.
- No grayscale, fill, texture wash, paper mockup, crayons, hands, or desk scene.
- No tiny trapped regions, broken contours, doubled limbs, or dense tangles.

## Quick check

Count every subject, inspect anatomy and closed contours, and verify the page contains only black lines, white space, usable margins, and age-appropriate region sizes.
