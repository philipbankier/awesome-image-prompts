# Fictional Board Game Token Set

## Use this when

Use this card for a coherent set of original board-game tokens shown as isolated components. Use a Recipe when game rules, manufacturing geometry, exact symbols, or evidence matters.

## Required inputs

- Fictional game theme and exact token manifest.
- Token shapes, materials, colors, symbols, and quantity.
- Presentation surface, camera view, lighting, spacing, and aspect ratio.

## Prompt

```text
SCENE
Create a controlled component-photography setup on {BACKGROUND}, lit by {LIGHTING}.

SUBJECT
Show exactly {TOKEN_MANIFEST} for the fictional game {GAME_NAME}, arranged in {LAYOUT} and viewed from {CAMERA_VIEW}.

DETAILS
Use {MATERIALS}, {COLOR_SYSTEM}, and {SYMBOL_SYSTEM}. Keep each token's silhouette, thickness, edge treatment, and symbol placement internally consistent across the set.

CONSTRAINTS
No real game branding, recognizable franchise symbols, board, cards, dice, box, hands, extra tokens, missing variants, fused pieces, unreadable pseudo-runes, logos, watermarks, letters, or numbers unless approved.

OUTPUT INTENT
Return one clean component-set image at {ASPECT_RATIO}, with every token fully visible, separated, and easy to compare.
```

## Variables

- `{BACKGROUND}`: simple studio or tabletop field.
- `{LIGHTING}`: direction, softness, fill, and shadow character.
- `{TOKEN_MANIFEST}`: exact token types, variants, and quantities.
- `{GAME_NAME}`: fictional internal name, not necessarily rendered.
- `{LAYOUT}`: row, grid, arc, or grouped arrangement.
- `{CAMERA_VIEW}`: top-down or oblique comparison view.
- `{MATERIALS}`: wood, resin, cardboard, metal, or other approved material.
- `{COLOR_SYSTEM}`: closed palette and variant mapping.
- `{SYMBOL_SYSTEM}`: original geometric marks and their mapping.
- `{ASPECT_RATIO}`: final width-to-height ratio.

## Negative constraints

- No recognizable trademark, heraldry, alphabet, numerals, or existing game iconography.
- No inconsistent scale, token thickness, bevel, symbol alignment, or material response.
- No extra game components or lifestyle scene.

## Quick check

Count all tokens by variant, compare dimensions and edge treatment, and inspect every symbol for originality, consistency, and correct mapping.
