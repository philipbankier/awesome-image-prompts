# Prompt Cards

Prompt Cards are fast, copy-ready starting points. Use one when you need a strong prompt without a full evaluation workflow. For production-critical work, switch to the linked flagship Recipe or the nearest entry in the [Recipe index](../skills/image-recipe-library/references/recipe-index.md).

This first wave contains 65 independently authored Cards, five in each category. Every Card currently has a clearly labeled Placeholder Preview. The 13 flagship Recipes have separate Recipe-owned illustrative samples; those runs do not turn the Cards into tested or promoted prompts.

The star marks the Card that expands into a full Recipe.
