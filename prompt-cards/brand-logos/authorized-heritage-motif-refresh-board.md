# Authorized Heritage Motif Refresh Board

## Use this when

Use this card when you need to refresh a fictional or otherwise authorized organization motif without replacing its identity. Use a Recipe or specialist identity review when trademark clearance, exact reproduction, production files, repair, or evidence matters.

## Required inputs

- Exact fictional brand name and approved descriptor or tagline.
- Brand brief, audience, personality, original symbol logic, and prohibited motifs.
- Typography direction, palette, exact copy manifest, touchpoint manifest, and output size.
- One attached reference image and confirmation that it is authorized for this use.
- A preservation manifest separating protected features from approved changes.

## Prompt

```text
COMMISSION
Create one 3:2 reference-led identity refresh board to refresh a fictional or otherwise authorized organization motif without replacing its identity. Use this independently authored concept: the preserved core motif is cleaned into a simpler spacing and stroke system.

REFERENCE INPUT
Use the attached authorized {REFERENCE_IMAGE} only for {REFERENCE_ROLE}. Preserve {PRESERVE_RULES}; change only elements explicitly permitted by the brief. Do not infer unseen geometry, replace an identity, alter protected copy, or import marks from the reference.

IDENTITY
Design an original identity for the fictional name {BRAND_NAME_EXACT} using {BRAND_BRIEF}. Build the mark from {SYMBOL_LOGIC}, pair it with {TYPE_DIRECTION}, and use only {PALETTE}. Render only {COPY_MANIFEST}.

SYSTEM
Apply the identity to {TOUCHPOINT_MANIFEST} using this arrangement: source motif reference left with approved refinement, wordmark pairing, and one-color test right. Keep symbol geometry, clear space, color roles, and wordmark spelling consistent across every shown use.

CONSTRAINTS
No real brand, copied trademark, stock logo, national emblem, celebrity likeness, unsupported claim, signature, watermark, or unapproved text. Show one coherent direction, not a page of alternative logos.

OUTPUT INTENT
Return one flat reference-led identity refresh board at {OUTPUT_SIZE} in 3:2, with legible exact naming and no photorealistic lifestyle scene unless a touchpoint requires it.
```

## Variables

- `{BRAND_NAME_EXACT}`: exact fictional brand or program name
- `{BRAND_BRIEF}`: purpose, audience, personality, differentiation, and prohibited motifs
- `{SYMBOL_LOGIC}`: original shapes, construction rule, and negative-space behavior
- `{TYPE_DIRECTION}`: project-owned wordmark and supporting typography character
- `{PALETTE}`: approved color names or values and one-color behavior
- `{COPY_MANIFEST}`: complete allowed naming and descriptor text
- `{TOUCHPOINT_MANIFEST}`: exact applications, formats, and content allowed on the board
- `{OUTPUT_SIZE}`: final pixel dimensions
- `{REFERENCE_IMAGE}`: attached authorized single reference image
- `{REFERENCE_ROLE}`: the sole role the reference may play in the composition
- `{PRESERVE_RULES}`: features, geometry, identity, copy, or relationships that must remain unchanged

## Negative constraints

- No real brand, confusingly similar trademark, stock icon, copied crest, national emblem, celebrity likeness, signature, or watermark.
- No misspelled wordmark, invented descriptor, unsupported claim, pseudo-text, inconsistent symbol, or unexplained color variation.
- No page of unrelated alternatives, photorealistic logo sculpture, excessive effects, or undeclared touchpoint.

## Quick check

Read the exact name and copy, compare symbol geometry and color roles across touchpoints, and check the intended system arrangement: source motif reference left with approved refinement, wordmark pairing, and one-color test right. This is not trademark clearance or production proof.
