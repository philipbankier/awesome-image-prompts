# Fictional Identity Moodboard Synthesis

## Use this when

Use this card when you need to synthesize several authorized material, color, and shape references into one original fictional identity direction. Use a Recipe or specialist identity review when trademark clearance, exact reproduction, production files, repair, or evidence matters.

## Required inputs

- Exact fictional brand name and approved descriptor or tagline.
- Brand brief, audience, personality, original symbol logic, and prohibited motifs.
- Typography direction, palette, exact copy manifest, touchpoint manifest, and output size.
- The complete attached source-image set, with authorization confirmed for every image.
- An image-role manifest and per-asset preservation rules.

## Prompt

```text
COMMISSION
Create one 3:2 multi-reference identity direction board to synthesize several authorized material, color, and shape references into one original fictional identity direction. Use this independently authored concept: distinct source roles produce a new symbol grammar rather than a collage.

SOURCE IMAGE SET
Use only the authorized images in {SOURCE_IMAGES}, assigning each exactly the role in {IMAGE_ROLE_MANIFEST}. Preserve {PRESERVE_RULES}. Keep people, products, artwork, and source identities separate unless the manifest explicitly authorizes a relationship; do not invent or merge assets.

IDENTITY
Design an original identity for the fictional name {BRAND_NAME_EXACT} using {BRAND_BRIEF}. Build the mark from {SYMBOL_LOGIC}, pair it with {TYPE_DIRECTION}, and use only {PALETTE}. Render only {COPY_MANIFEST}.

SYSTEM
Apply the identity to {TOUCHPOINT_MANIFEST} using this arrangement: role-labeled references at the edge with one original mark, palette, type direction, and touchpoint center. Keep symbol geometry, clear space, color roles, and wordmark spelling consistent across every shown use.

CONSTRAINTS
No real brand, copied trademark, stock logo, national emblem, celebrity likeness, unsupported claim, signature, watermark, or unapproved text. Show one coherent direction, not a page of alternative logos.

OUTPUT INTENT
Return one flat multi-reference identity direction board at {OUTPUT_SIZE} in 3:2, with legible exact naming and no photorealistic lifestyle scene unless a touchpoint requires it.
```

## Variables

- `{BRAND_NAME_EXACT}`: exact fictional brand or program name
- `{BRAND_BRIEF}`: purpose, audience, personality, differentiation, and prohibited motifs
- `{SYMBOL_LOGIC}`: original shapes, construction rule, and negative-space behavior
- `{TYPE_DIRECTION}`: project-owned wordmark and supporting typography character
- `{PALETTE}`: approved color names or values and one-color behavior
- `{COPY_MANIFEST}`: complete allowed naming and descriptor text
- `{TOUCHPOINT_MANIFEST}`: exact applications, formats, and content allowed on the board
- `{OUTPUT_SIZE}`: final pixel dimensions
- `{SOURCE_IMAGES}`: complete set of attached authorized source images
- `{IMAGE_ROLE_MANIFEST}`: one permitted role for each source image
- `{PRESERVE_RULES}`: per-image identity, geometry, copy, crop, and relationship constraints

## Negative constraints

- No real brand, confusingly similar trademark, stock icon, copied crest, national emblem, celebrity likeness, signature, or watermark.
- No misspelled wordmark, invented descriptor, unsupported claim, pseudo-text, inconsistent symbol, or unexplained color variation.
- No page of unrelated alternatives, photorealistic logo sculpture, excessive effects, or undeclared touchpoint.

## Quick check

Read the exact name and copy, compare symbol geometry and color roles across touchpoints, and check the intended system arrangement: role-labeled references at the edge with one original mark, palette, type direction, and touchpoint center. This is not trademark clearance or production proof.
