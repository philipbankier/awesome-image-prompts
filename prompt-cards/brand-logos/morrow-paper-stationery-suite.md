# Morrow Paper Stationery Suite

## Use this when

Use this card when you need to show a fictional research consultancy identity on restrained stationery. Use a Recipe or specialist identity review when trademark clearance, exact reproduction, production files, repair, or evidence matters.

## Required inputs

- Exact fictional brand name and approved descriptor or tagline.
- Brand brief, audience, personality, original symbol logic, and prohibited motifs.
- Typography direction, palette, exact copy manifest, touchpoint manifest, and output size.

## Prompt

```text
COMMISSION
Create one 3:2 stationery identity suite to show a fictional research consultancy identity on restrained stationery. Use this independently authored concept: a horizon rule aligns letterhead, card, envelope, and report cover.

IDENTITY
Design an original identity for the fictional name {BRAND_NAME_EXACT} using {BRAND_BRIEF}. Build the mark from {SYMBOL_LOGIC}, pair it with {TYPE_DIRECTION}, and use only {PALETTE}. Render only {COPY_MANIFEST}.

SYSTEM
Apply the identity to {TOUCHPOINT_MANIFEST} using this arrangement: flat orthographic suite with exact copy zones and no lifestyle props. Keep symbol geometry, clear space, color roles, and wordmark spelling consistent across every shown use.

CONSTRAINTS
No real brand, copied trademark, stock logo, national emblem, celebrity likeness, unsupported claim, signature, watermark, or unapproved text. Show one coherent direction, not a page of alternative logos.

OUTPUT INTENT
Return one flat stationery identity suite at {OUTPUT_SIZE} in 3:2, with legible exact naming and no photorealistic lifestyle scene unless a touchpoint requires it.
```

## Variables

- `{BRAND_NAME_EXACT}`: exact fictional brand or program name
- `{BRAND_BRIEF}`: purpose, audience, personality, differentiation, and prohibited motifs
- `{SYMBOL_LOGIC}`: original shapes, construction rule, and negative-space behavior
- `{TYPE_DIRECTION}`: project-owned wordmark and supporting typography character
- `{PALETTE}`: approved color names or values and one-color behavior
- `{COPY_MANIFEST}`: complete allowed naming and descriptor text
- `{TOUCHPOINT_MANIFEST}`: exact applications, formats, and content allowed on the board
- `{OUTPUT_SIZE}`: final pixel dimensions

## Negative constraints

- No real brand, confusingly similar trademark, stock icon, copied crest, national emblem, celebrity likeness, signature, or watermark.
- No misspelled wordmark, invented descriptor, unsupported claim, pseudo-text, inconsistent symbol, or unexplained color variation.
- No page of unrelated alternatives, photorealistic logo sculpture, excessive effects, or undeclared touchpoint.

## Quick check

Read the exact name and copy, compare symbol geometry and color roles across touchpoints, and check the intended system arrangement: flat orthographic suite with exact copy zones and no lifestyle props. This is not trademark clearance or production proof.
